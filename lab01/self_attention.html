Self-Attention Schritt für Schritt

Lab 01c mit dem Satz "Life is too short for bad coffee", d = 8, dq = dk = 24, dv = 28. Alle Zahlen sind mit torch.manual_seed(42) berechnet, genau wie im Notebook, wenn jede Zelle einmal der Reihe nach läuft.

X: Embeddings Q: Queries K: Keys V: Values Z: Context-Vektoren

1Vom Satz zur Matrix X

Jedes Wort wird über das vocab zu einer ID. Die ID wählt eine Zeile aus der Embedding-Tabelle. Übereinandergestapelt ergibt das X: eine Zeile pro Token, 8 Spalten pro Token.

Blau = positiver Wert, Rot = negativer Wert. Die Zahlen sind zufällig, weil das Embedding noch nicht trainiert ist.

2Drei Projektionen: X → Q, K, V

Dieselben drei Matrizen werden auf jedes Token angewendet. Die hervorgehobene Zeile zeigt das Token : Sein Vektor mit 8 Werten wird mit der ganzen Matrix multipliziert und ergibt eine Zeile mit 24 bzw. 28 Werten.

Hier in Zeilenform geschrieben (X @ W.T). Das Notebook rechnet in Spaltenform, K = W_k @ X.T, ergibt also 24 × 7. Der Inhalt ist derselbe, nur transponiert.

3Scores: jede Query gegen jeden Key

Ω = Q · Kᵀ. Eintrag (i, j) ist das Skalarprodukt qi · kj, also wie gut die Query von Token i zum Key von Token j passt. Dafür müssen q und k gleich lang sein (dq = dk = 24).

Wähle ein Query-Token:

Ω: rohe Scores

Zeile = Query (wer schaut), Spalte = Key (wird angeschaut).

A = softmax(Ω / √24), zeilenweise

Jede Zeile summiert sich zu 1. Das sind die Attention-Gewichte.

4Gewichtete Summe der Values: Z = A · V

Für Token wird jeder Value-Vektor vj mit dem Gewicht aij multipliziert, dann wird alles aufsummiert. Das Ergebnis zi hat die Länge dv = 28 und enthält Information aus dem ganzen Satz.

Z = softmax( (X·Wqᵀ) · (X·Wkᵀ)ᵀ / √dk ) · (X·Wvᵀ)

Die Gewichte in A sind hier sehr einseitig: Fast alle Tokens schauen auf for. Das ist kein Sprachmuster, sondern kommt von den untrainierten Matrizen. torch.rand liefert nur positive Werte, deshalb dominiert ein Token mit grossem Key. Erst durch das Training lernen Wq, Wk und Wv sinnvolle Beziehungen, zum Beispiel dass short auf Life schaut.
